# StoryLoom

StoryLoom is a creative web app for writing and collecting micro-stories.

## Core idea
- Users log in
- Choose a prompt (or roll one)
- Write a short story (e.g., 280–1000 chars)
- Save into "Collections" (themes like "campfire", "sci-fi", "cozy mystery")
- Explore and remix prompts

## Why this is broad-appeal
Anyone who likes writing, journaling, roleplay, or creativity can use it. Not dev-centric.

## MVP scope
- Auth (Google + email/password)
- Prompts: built-in + user-created
- Stories: create/edit/delete, attach to prompt
- Collections: organize stories
- Public gallery (opt-in) later
